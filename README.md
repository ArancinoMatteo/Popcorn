# 🍿 Popcorn - Your Personal Android Media Hub

[![Java](https://img.shields.io/badge/java-%23ED8B00.svg?style=for-the-badge&logo=openjdk&logoColor=white)](https://www.java.com/)
[![Android XML](https://img.shields.io/badge/Android%20UI-3DDC84?style=for-the-badge&logo=android&logoColor=white)](https://developer.android.com/guide/topics/ui)
[![Media3 ExoPlayer](https://img.shields.io/badge/Media3_ExoPlayer-4285F4?style=for-the-badge&logo=android&logoColor=white)](https://developer.android.com/guide/topics/media/media3)

**Popcorn** è un media player locale per Android progettato per offrire un'esperienza visiva premium, simile alle principali piattaforme di streaming. Ti permette di importare i tuoi file video (film e serie TV), organizzandoli automaticamente con locandine, trame e metadati ufficiali in un'interfaccia moderna e reattiva.

---

## ✨ Caratteristiche Principali

*   **📺 Interfaccia Stile Netflix:** Design moderno costruito con layout XML nativi e `RecyclerView`. Caroselli fluidi per categorie, effetti di transizione e una sezione "Hero" per i contenuti in evidenza.
*   **🧠 Metadati Automatici:** Integrazione con l'API di [TMDB (The Movie Database)](https://www.themoviedb.org/) per scaricare automaticamente poster in alta risoluzione, sfondi (backdrop), cast e descrizioni partendo dal nome del file.
*   **▶️ Riproduzione Avanzata:** Basato su **AndroidX Media3 (ExoPlayer)** per garantire compatibilità con formati complessi (MKV, MP4, HDR), tracce audio multiple e gestione dei sottotitoli.
*   **⏱️ Continua a Guardare:** Database locale integrato per tenere traccia dei progressi di riproduzione. Riprendi esattamente da dove avevi interrotto, con una barra di avanzamento dedicata per ogni video.
*   **📁 Gestione File Locale:** Accesso ottimizzato allo storage interno e alle memorie esterne (OTG/USB) tramite Storage Access Framework (SAF).
